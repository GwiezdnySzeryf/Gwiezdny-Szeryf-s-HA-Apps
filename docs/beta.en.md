# 🧪 Photo Frame Drop Beta

**Photo Frame Drop Beta** is a testing version for enthusiasts who want to try out the latest features and fixes right before they land in the official release.

!!! warning "Heads up"
    The Beta version may contain bugs. Installing it in production environments where stability is critical is not recommended.

---

## Differences from the stable version

| | Stable | Beta |
|---|:---:|:---:|
| Stability | ✅ Tested | ⚠️ In testing |
| New features | After release | Immediately |
| Recommended for daily use | ✅ | ⚠️ |

---

## Installation

Installation is identical to the [stable version](photo-frame-drop/installation.md) — simply select **Photo Frame Drop Beta** from the list in the Add-on Store after adding the repository.

You can have both versions installed at the same time.

---

## Reporting bugs

If you find a bug in the Beta, please report it via [GitHub Issues](https://github.com/GwiezdnySzeryf/Gwiezdny-Szeryf-s-HA-Apps/issues) — it's the most helpful way to contribute to the project's development.
