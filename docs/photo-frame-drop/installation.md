# Instalacja

## Przez przycisk (najszybciej)

Kliknij poniższy przycisk — Home Assistant otworzy się z już wypełnionym adresem repozytorium:

[![Dodaj repozytorium do HA](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FGwiezdnySzeryf%2FGwiezdny-Szeryf-s-HA-Apps)

Po przekierowaniu kliknij **Dodaj** i przejdź do [konfiguracji](configuration.md).

---

## Ręcznie krok po kroku

### 1. Dodaj repozytorium

1. W Home Assistant przejdź do **Ustawienia → Dodatki**
2. Kliknij **Sklep z dodatkami** (prawy dolny róg)
3. Kliknij **⋮** (trzy kropki) w prawym górnym rogu → **Repozytoria**
4. Wklej adres URL i kliknij **Dodaj**:
   ```
   https://github.com/GwiezdnySzeryf/Gwiezdny-Szeryf-s-HA-Apps
   ```
5. Zamknij okno repozytoriów

### 2. Zainstaluj dodatek

1. Odśwież stronę Sklepu z dodatkami (Ctrl+F5 lub F5)
2. Znajdź sekcję **GwiezdnySzeryf's HA Apps** na dole listy
3. Kliknij **Photo Frame Drop** → **Zainstaluj**
4. Poczekaj na zakończenie instalacji

### 3. Uruchom i skonfiguruj

Po instalacji przejdź do zakładki **Konfiguracja** w dodatku — szczegóły znajdziesz na stronie [Konfiguracja](configuration.md).

---

## Aktualizacje

Home Assistant automatycznie powiadomi Cię o dostępnych aktualizacjach. Możesz je zastosować z poziomu **Ustawienia → Dodatki → Photo Frame Drop → Aktualizuj**.

!!! note
    Jeśli wolisz mieć dostęp do najnowszych funkcji przed oficjalnym wydaniem, rozważ równoległą instalację [Photo Frame Drop Beta](../beta.md).
