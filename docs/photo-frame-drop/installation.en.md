# Installation

## Via button (fastest)

Click the button below — Home Assistant will open with the repository URL pre-filled:

[![Add repository to HA](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FGwiezdnySzeryf%2FGwiezdny-Szeryf-s-HA-Apps)

Click **Add** and proceed to [configuration](configuration.md).

---

## Manual step-by-step

### 1. Add the repository

1. In Home Assistant go to **Settings → Add-ons**
2. Click **Add-on Store** (bottom right corner)
3. Click **⋮** (three dots) in the top right → **Repositories**
4. Paste the URL and click **Add**:
   ```
   https://github.com/GwiezdnySzeryf/Gwiezdny-Szeryf-s-HA-Apps
   ```
5. Close the repositories dialog

### 2. Install the add-on

1. Refresh the Add-on Store page (Ctrl+F5 or F5)
2. Find the **GwiezdnySzeryf's HA Apps** section at the bottom of the list
3. Click **Photo Frame Drop** → **Install**
4. Wait for the installation to complete

### 3. Start and configure

After installation, go to the **Configuration** tab in the add-on — details on the [Configuration](configuration.md) page.

---

## Updates

Home Assistant will automatically notify you of available updates. You can apply them from **Settings → Add-ons → Photo Frame Drop → Update**.

!!! note
    If you prefer to access the latest features before the official release, consider installing [Photo Frame Drop Beta](../beta.md) alongside the stable version.
